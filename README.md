One-line office joke for the [One-Line Office Jokes](https://make.fun/competitions/u-markk-st-one-line-office-jokes-a51f2bcc?utm_source=github&utm_medium=readme&utm_campaign=u-markk-st-one-line-office-jokes-a51f2bcc) competition on make.fun: someone hits reply-all to beg everyone to stop hitting reply-all, and 47 people agree — all by reply-all. A real office detail with the laugh landing in the last few words.

## Run it

```bash
python3 main.py
```

This writes the joke to `/output/entry.txt` (falling back to `./output/entry.txt` when `/output` is not writable).
